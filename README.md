## 4. 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？
**答：** 因為 `"4"` 在 Python 中是字串（`str`）型別，字串不具備數學除法運算的功能。如果直接拿字串去除以總金額（例如 `1220 / "4"`），Python 會跳出 `TypeError` 錯誤。因此必須先透過 `int("4")` 將其轉換成整數（`int`）後，才能進行正確的數學除法計算。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？
**答：** 
* **計算結果：** 
  1. 扣除折價券後金額：$1,200 - 100 = 1,100$ 元。
  2. 計算服務費：$1,100 \times 10\% = 110$ 元。
  3. 應付總額：$1,100 + 110 = 1,210$ 元。
* **原因說明：** 餐廳的服務費通常是以「原始消費金額」作為計算基準（即服務生提供服務的原始餐點價值），而不是扣除店家優惠折價券後的折後金額。若先扣折價券再算服務費，服務費的計算基準會變少，導致餐廳實際收到的服務費與總額與合約規定不符。
